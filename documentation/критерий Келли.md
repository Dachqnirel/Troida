# Определение
**Критерий Келли** — это формула для определения процента от капитала, которым можно рисковать. 

# Формула расчета
$$K =\frac{bp - q}{b}$$

Пояснение к формуле:
- K — доля капитала, которую можно инвестировать
- b — коэффицент прибыли (отношение средней прибыли к среднему убытку)
- p — вероятность прибыльной сделки (отношение прибыльных ко всем сделкам) 
- q - вероятность убыточной сделки (1 - p)
