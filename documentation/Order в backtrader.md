## Определение
- Order - это команда, которая отправляется брокеру
- мы явно создаем ордера с помощью `buy(), close()` и других методов
- в отличии от [[Trade в backtrader|объекта Trade]] мы можем управлять ордером (например отменить его)

## Стадии (статусы) ордеров
| Статус        | Описание                                                                          |
| ------------- | --------------------------------------------------------------------------------- |
| **Created**   | Ордер создан                                                                      |
| **Submitted** | Ордер отправлен брокеру (в режиме бэктеста это происходит мнгновенно)             |
| **Accepted**  | Ордер принят брокером и ожидает исполнения согласно заданным параметрам           |
| **Partial**   | Ордер частично исполнен                                                           |
| **Completed** | Ордер полностью исполнен                                                          |
| **Canceled**  | Ордер был отменён пользователем до исполнения                                     |
| **Expired**   | Ордер с ограниченным сроком действия истёк                                        |
| **Margin**    | Ордер удален из-за возможного маржин-колла                                        |
| **Rejected**  | Ордер отклонён брокером из-за недопустимых параметров или недостаточного капитала |

## Типы ордеров 
| Тип                         | Описание                                                                                                      |
| --------------------------- | ------------------------------------------------------------------------------------------------------------- |
| **Market** (рыночный)       | исполняется по следующей доступной цене                                                                       |
| **Limit** (лимитный)        | исполняется по указанной цене или лучше                                                                       |
| **Stop**                    | активируется при достижении определённой цены и исполняется как рыночный ордер.                               |
| **StopLimit**               | активируется при достижении стоп-цены и исполняется как лимитный ордер по указанной лимит-цене.               |
| **Close**                   | исполняется по цене закрытия текущей сессии                                                                   |
| **StopTrail**               | стоп-цена автоматически следует за ценой на определённое расстояние                                           |
| **StopTrailLimit**          | сочетает в себе трейлинг-стоп и лимит, активируется при достижении стоп-цены и исполняется как лимитный ордер |
| **Bracket**                 | состоит из основного ордера, стоп-лосса и тейк-профита                                                        |
| **OCO** (One Cancels Other) | группа ордеров, где исполнение одного приводит к автоматической отмене остальных.                             |
