# Каналы Дончиана (Donchian Channel)

## 1. Идея индикатора

Каналы Дончиана — это трендовый индикатор, построенный на основе
**максимумов и минимумов** цены за некоторый период. Он показывает:

- верхнюю границу диапазона цен (максимумы за N баров);
- нижнюю границу диапазона цен (минимумы за N баров);
- центральную линию (обычно середина между верхней и нижней).

Интуиция: 
- если цена пробивает верхнюю границу — рынок выходит на новые локальные максимумы → возможен **тренд вверх**;
- если пробивает нижнюю границу — новые минимумы → возможен **тренд вниз**;
- если канал сужается, рынок сжимается в диапазон → потенциально готовится **импульс / пробой**.

Индикатор сделан Ричардом Дончианом, которого часто называют одним из «отцов» трендследования.
На основе каналов Дончиана построена известная система «Черепах» (Turtle Trading).

---

## 2. Формулы и расчёт

Пусть N — период (например, 20 баров). Тогда для бара *t*:

- Верхняя линия (Upper Donchian Channel):

\[
Upper_t = \max(High_{t-N+1}, \dots, High_t)
\]

- Нижняя линия (Lower Donchian Channel):

\[
Lower_t = \min(Low_{t-N+1}, \dots, Low_t)
\]

- Средняя линия (Middle Donchian Channel):

\[
Middle_t = \frac{Upper_t + Lower_t}{2}
\]

Обычно:

- берут **High/Low** (а не Close);
- N = 20, 55 и т.п., в зависимости от таймфрейма и стиля торговли.

---

## 3. Интерпретация

### 3.1. Пробои и тренды

Классическая логика:

- **Пробой вверх** (цена выходит выше верхней линии):
    - рынок обновляет максимум за N баров;
    - считается сигналом на **покупку по тренду**;
- **Пробой вниз** (цена падает ниже нижней линии):
    - рынок обновляет минимум за N баров;
    - считается сигналом на **продажу по тренду / шорт**.

Важно: каналы Дончиана — не осциллятор, они не говорят «перекуплен / перепродан», а **фиксируют экстремумы диапазона**.

### 3.2. Ширина канала

- **Широкий канал** — высокая волатильность рынка.
- **Узкий канал** — сжатие волатильности, консолидация, часто перед сильным движением.

## 4. Типичные торговые правила

### 4.1. Простая трендовая система

Пример (аналог идей Turtle System):

- Параметр N (например, 20).
- **Вход в лонг:** когда закрытие пересекает верхнюю границу:
    - `Close_t > Upper_{t-1}`.
- **Вход в шорт:** когда закрытие пересекает нижнюю границу:
    - `Close_t < Lower_{t-1}`.
- **Выход:** при обратном пробое или выходе к средней/противоположной границе.
    - Например, для лонга выйти, если `Close_t < Middle_{t-1}` или даже `Close_t < Lower_{t-1}` (жёсткий стоп).

Для избежания подглядывания (look-ahead bias) часто берут **границы канала на предыдущем баре**.

### 4.2. Фильтрация ложных сигналов

Чтобы уменьшить количество ложных пробоев:

- использовать **ATR-стопы** (волатильностные защитные стопы),
- игнорировать сигналы, если ширина канала слишком мала,
- торговать только в сторону старшего тренда,
- минимальный объём/ликвидность.

---

## 5. Преимущества и недостатки

### Плюсы

- Простая и прозрачная логика.
- Чёткие уровни для входа и выхода.
- Подходит для трендовых стратегий и пробоя диапазона.
- Легко реализуется в любом терминале/языке.

### Минусы

- В боковиках дает много ложных пробоев и перезаходов.
- Не показывает силу тренда, только факт выхода за диапазон.
- Сигнал может приходить поздно (после того, как часть движения уже прошла).

---

## 6. Где использовать

- Трендследующие системы на дневных / 4H / часовиках.
- Фьючерсы, валюты, акции, сырьё — везде, где есть длинные тренды.
- Как фильтр: не торговать контртрендовые паттерны, пока цена держится за пределами канала.

---

## 7. Стратегия для backtrader

Ниже пример базовой стратегии:

- Индикатор: каналы Дончиана с периодом N = 20.
- Вход:
    - лонг при пробое верхней границы;
    - шорт при пробое нижней границы.
- Выход:
    - для лонга — при уходе ниже средней линии;
    - для шорта — при уходе выше средней линии.
- Опционально: ATR-стопы и фиксированный риск на сделку.
