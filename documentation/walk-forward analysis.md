# Что это такое:
**Walk-forward analysis (WFA)** — это метод тестирования торговых стратегий, который разделяет данные на обучающие и тестовые периоды:

![[Pasted image 20250409232140.png]]


# Выбор параметров для тестирования:
### 1. **Длина обучающего периода (In-Sample)**
- **Краткосрочные стратегии** (например, скальпинг или внутридневная торговля): обучающий период может быть относительно коротким, например, 1–3 месяца.
- **Среднесрочные стратегии** (например, свинг-торговля): обучающий период может составлять 6–12 месяцев.
- **Долгосрочные стратегии** (например, позиционная торговля): обучающий период может быть 1–3 года или больше.

### 2. **Длина тестового периода (Out-of-Sample)**
- Тестовый период должен быть достаточно длинным, чтобы оценить устойчивость стратегии, но не слишком длинным, чтобы избежать устаревания модели. Обычно это 1–6 месяцев для краткосрочных стратегий и 6–12 месяцев для долгосрочных.
- Рекомендуется использовать несколько тестовых периодов (например, 3–5), чтобы проверить стабильность стратегии в разных рыночных условиях. Чем больше таких итераций будет тем лучше.

### 3. **Шаг смещения (Rolling Window)**
- Шаг смещения определяет, насколько часто обновляется обучающий период. Например, если шаг составляет 1 месяц, то каждый месяц добавляются новые данные, а старые удаляются.
- Для краткосрочных стратегий шаг может быть меньше (например, 1 неделя), для долгосрочных — больше (например, 3 месяца).
