## 1) Определение и главная информация  
**Современные продвинутые техники** — набор методов алгоритмической торговли, основанных на машинном обучении, эволюционных вычислениях и нечётких логиках. Цель — автоматическая адаптация к изменяющимся рыночным условиям и извлечение сигналов на основе сложных паттернов.

### Основные направления:  
- **Нейронные сети** — модели (MLP, **LSTM**, **Transformer**) для анализа ценовых рядов.  
- **Генетические алгоритмы** — эволюционная оптимизация параметров стратегий.  
- **Нечёткие системы** — формализация экспертных правил (“цена высокая”, “сильный тренд”).  
- **Репликация стратегий** — обратная инженерия логики хедж-фондов на основе публичных данных.

## 2) Углубление в код, формулы, особенности  
- **Нейронные сети**:  
	y = f(W₂·σ(W₁·x + b₁) + b₂)
- **LSTM** контролирует долгосрочную память с помощью ворот:  
	iₜ = σ(Wᵢ·[hₜ₋₁, xₜ] + bᵢ)  
	fₜ = σ(Wf·[hₜ₋₁, xₜ] + bf) ...
	
- **Генетические алгоритмы**:  
- Хромосома = набор параметров (период SMA, пороги RSI и т. д.)  
- Операторы: **скрещивание**, **мутация**, **селекция**  

- **Нечёткая логика**:  
- Функции принадлежности (треугольные, гауссовы)  
- Правило: “Если RSI высокий **И** волатильность низкая, **ТО** шорт”  

- **Репликация стратегий**:  
- Формирование портфеля CTA на основе отраслевых весов и риска  
- Monte Carlo для стресс-тестирования
