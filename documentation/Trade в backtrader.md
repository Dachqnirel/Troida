# Определение:
- Объект Trade создается, когда объем позиции в инструменте становится больше нуля
- Trade закрывается, когда объем позиции становится нулевым

| Атрибут    | Описание                                                                                               |
| ---------- | ------------------------------------------------------------------------------------------------------ |
| ref        | номер сделки (типо id)                                                                                 |
| size       | текущий объем сделки (например 100 акций). если сделка закрыта, то size = 0                            |
| price      | средняя цена входа в сделку                                                                            |
| value      | текущая стоимость сделки (например 10 акций по 100р, значит value = 1000р)                             |
| commission | сколько комиссии было заплачено в абсолютном значении (в деньгах)                                      |
| pnl        | профит/убыток сделки в абсолютном значении (в деньгах)                                                 |
| pnlcomm    | то же что pnl, но с учетом комиссии                                                                    |
| baropen    | номер бара открытия сделки                                                                             |
| barclose   | номер бара закрытия сделки                                                                             |
| dtopen     | время открытия сделки (чтобы получить объект datetime.datetime нужно использовать метод open_datetime) |
| dtclose    | время закрытия сделки (чтобы получить объект datetime.datetime нужно использовать метод open_datetime) |
| isopen     | открыта ли сейчас сделка (True/False)                                                                  |
| isclosed   | закрыта ли сейчас сделка (True/False)                                                                  |


# Пример использования в коде:
```python
# эта фунция вызывается в объекте Strategy и Analyzer, когда сделка открывается, изменяется или закрывается
def notify_trade(self, trade):
	if trade.isopen:  
	    # Сделка только открылась  
		print(f"Я открыл сделку по цене {trade.price} на {trade.size} акций")
  
	elif trade.isclosed:  
		# Сделка полностью закрылась
		print(f"Я закрыл сделку с абсолютной прибылью {trade.pnl}")

```
