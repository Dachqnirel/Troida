### Задачи:
1. Разработка алгоритма, который будет автоматически черпать данные через API с использованием возможностей от [Т-Инвестиций](https://www.tbank.ru/invest/form/start/?utm_source=yandex&utm_medium=ctx.cpc&utm_campaign=inv_ctx_pf_cl_ya_n_search.to_brand.inv_creo-10rub_0425_rus_cdev_cenv_n&utm_term=n_n_n_kw.---autotargeting&utm_content=n-n_n_n_cid.700000532_aid.1874766426361214232_pid.205579075422_retid.205579075422_dvc.desktop_gid.5579075422_src.none_regionid.213_postype.premium_pos.1_corid.34961553&yclid=8954142717313023999).
2. Коллекционирование данных в .csv файлах;
3. Обработка данных:
 * Коррекция на дивиденды.
    При выплате дивидендов цена акции обычно падает на размер дивиденда. Нужно корректировать исторические цены, чтобы учесть дивиденды.
    ![image](https://img2.teletype.in/files/13/65/13654944-9ca3-4f0d-8e5a-c3cebf1fe184.png)
 * Коррекция на допэмиссию. Допэмиссия это когда на рынок выходят новые акции, часто после этого цена инструмента резко падает до цены объявленный допэмиссии.
 * Коррекция на вечернюю или выходную сессию. Если у инструмента низкая ликвидность в периоды вечерней или выходной сессии лучше убирать это периоды, потому что зачастую эти периоды имеют множество артефактных свеч.
 * Коррекция на общие/утренние гэпы. Отслеживание общих и утренних промежутков с гэпами в цене, это будет сильным шумом для ML модели.
 * Коррекция на долгий поковик. Отслеживание когда цена инструмента вовсе не меняет своей цены.
